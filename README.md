# Exercícios de Programação

Repositório em evolução com soluções de exercícios de programação resolvidos em diferentes linguagens.

## Status do projeto

Novos exercícios serão adicionados aos poucos, mantendo a organização por número de exercício e por linguagem.

## Estrutura

```text
.
├── ex001/
├── ex002/
├── ex003/
├── ex004/
└── README.md
```

Cada pasta de exercício pode conter soluções em mais de uma linguagem, além de arquivos auxiliares usados durante os estudos.

## Exercícios publicados

- **ex001** — print Hello, World!
- **ex002** — Soma de inteiros
- **ex003** — Fibonacci
- **ex004** — Area do círculo.

## Objetivo

Este repositório foi criado para praticar lógica de programação, consolidar o aprendizado em diferentes linguagens e manter um histórico organizado da evolução dos exercícios resolvidos.

## Como navegar

- Entre na pasta do exercício desejado.
- Abra a solução da linguagem que quiser estudar.
- Compare as implementações para entender diferenças de sintaxe e abordagem.

## Organização futura

A ideia é continuar adicionando novos exercícios neste mesmo repositório, preservando a sequência numérica e facilitando a consulta depois.
