# ex005 — beecrowd 1003: Soma Simples

Soluções da questão **1003** do beecrowd, implementadas em diferentes linguagens.

## Enunciado
Ler dois valores inteiros e mostrar a soma no formato:

```text
SOMA = X
```

## Exemplo

### Entrada
```text

```

### Saída
```text
SOMA = 40
```

## Objetivo

Este repositório foi criado para praticar lógica de programação e comparar a mesma solução em linguagens diferentes.
