# Beecrowd 1007 - Diferença

Este diretório contém as minhas resoluções para o problema **1007 (Diferença)** do [Beecrowd](https://judge.beecrowd.com/pt/problems/view/1007)[cite: 8]. Este é um projeto prático pessoal com o objetivo de manter a fluência nas linguagens de programação que utilizo.

## 🎯 O Problema

O exercício requer a leitura de quatro valores inteiros (A, B, C e D)[cite: 8]. O objetivo é calcular e mostrar a diferença do produto de A e B pelo produto de C e D[cite: 8].

A saída deve imprimir a mensagem "DIFERENCA" com todas as letras maiúsculas, com um espaço em branco antes e depois da igualdade, seguida do valor calculado[cite: 8].

**Fórmula aplicada:**
$$DIFERENCA = (A * B - C * D)$$

## 💻 Soluções Implementadas

O problema foi resolvido em três linguagens distintas, localizadas nas seguintes pastas do diretório `ex011`[cite: 7]:

- **C:** `c/main.c`[cite: 7].
- **Java:** `java/Main.java`[cite: 7] (utilizando a classe `Scanner` para a leitura dos inteiros[cite: 7]).
- **Python:** `python/main.py`[cite: 7].
