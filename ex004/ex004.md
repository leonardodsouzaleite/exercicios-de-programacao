# Exercício 004 — Área do Círculo

## Descrição

Dado o raio `r` de um círculo, calcule sua área usando a fórmula:

```
A = π × r²
```

O valor de π utilizado nas implementações é **3.14159**.

### Entrada

Um número de ponto flutuante representando o raio do círculo.

### Saída

A área do círculo no formato:

```
A=<valor>
```

com 4 casas decimais.

### Exemplo

| Entrada | Saída      |
|---------|------------|
| `2.0`   | `A=12.5664` |
| `5.0`   | `A=78.5398` |

---

## Implementações

### Python (`python/ex004.py`)

```python
import math

t0 = float(input())

area = round(math.pi, 5) * (t0**2)

print(f"A={area:.4f}")
```

> Utiliza `math.pi` arredondado para 5 casas decimais (equivalente a 3.14159).

---

### C (`c/ex004.c`)

```c
#include <math.h>
#include <stdio.h>

const double PI = 3.14159;

int main(int argc, char *argv[]) {
  double t0;
  scanf("%lf", &t0);

  double area = PI * pow(t0, 2);

  printf("A=%.4f\n", area);

  return 0;
}
```

> Para compilar: `gcc ex004.c -o ex004 -lm`

---

### Java (`java/ex004.java`)

```java
import java.util.Scanner;

public class ex004 {

  static final double PI = 3.14159;

  public static void main(String[] args) {
    Scanner sc = new Scanner(System.in);

    Double t0 = sc.nextDouble();

    double area = PI * Math.pow(t0, 2);

    System.out.printf("A=%.4f%n", area);

    sc.close();
  }
}
```

> Para compilar e executar:
> ```
> javac ex004.java
> java ex004
> ```

### Assembly RISC-V (`assembly/ex004.asm`)

```asm
section .data
  pi: dq 3.14159
  x: db "X="

section .text
  global _start

_start:
  li a7, 7
  ecall
  
  mv t0, a0

  mul t0, t0, t0

  li t1, pi

  mul t0, t1, t0

  mv a0, t0
  li a7, 3
  ecall
```

> Simulado via **RARS** (RISC-V Assembler and Runtime Simulator). O arquivo `rars.jar` está incluído no repositório.
